Verification performed on the build machine (Windows, x64)
  clean build                 python motonav/firmware/simulator/build.py --clean  -> ok
  scene enumeration           motonav-sim --list-scenes                          -> 20 scenes
  headless panel export       --scene cells-demo --headless --frames 3 --screenshot -> 360x360 PNG
  scene contract suite        python motonav/firmware/tests/simulator_scene_test.py
                              -> 18 of 19 pass. The failing one is pre-existing and
                                 unrelated to packaging: the test asks for scenes
                                 dashboard-speed-zero / dashboard-speed-32, which the
                                 current simulator does not define, so it errors with
                                 "unknown scene".

Not verified / out of scope
  No real device flashing, no real phone Bluetooth, no map or weather service, no QSPI
  timing, no panel frame rate. Desktop frame rate and memory use do not represent ESP32.
  The navigation page is not ported: nav-arrow / nav-cruise / nav-stale render
  "NAV PAGE NOT PORTED YET" on screen by design.
